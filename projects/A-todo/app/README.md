# A-todo

Ứng dụng quản lý việc cá nhân, chạy local, không đăng nhập, không backend. Dữ liệu lưu trong `localStorage` của trình duyệt.

## Chạy local

Cần Node.js 18+.

```bash
cd projects/A-todo/app
npm install
npm run dev
```

Mở URL Vite in ra (thường là `http://localhost:5173`).

## Lệnh khác

```bash
npm run build
npm run preview
```

## Phạm vi

Đúng 7 user story: xem danh sách, thêm, sửa tiêu đề, xóa, đánh dấu xong, lọc All/Active/Done, giữ dữ liệu sau khi tải lại trang.
